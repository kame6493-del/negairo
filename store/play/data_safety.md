# データ セーフティ(回答案)

## データの収集と共有
- アプリは、必須のユーザーデータの種類のいずれかを収集または共有しますか? → いいえ
  - 写真・カメラの映像は端末の中だけで処理し、外部へ送らない(Google の定義では「収集」に当たらない: 端末外に送信しないデータ)。
  - 購入の確認(RevenueCat)は、Google Play 請求の購入トークンとアプリごとの匿名 ID だけ。Google の「データ セーフティ」では、アプリの機能(購入の管理)のためにサービス提供元へ送るデータとして扱う。
  - 迷ったら「アプリのアクティビティ > アプリ内での購入履歴: 収集する / 共有しない / 任意ではない / 目的: アプリの機能」と答える(RevenueCat の公式の案内に合わせる。登録時に https://www.revenuecat.com/docs/platform-resources/google-play-data-safety を確認する)。
- 送信中のデータは暗号化されますか? → はい(RevenueCat との通信は HTTPS)
- データの削除をリクエストする方法 → アカウントが無く、端末の外に個人のデータを持たないため、アプリの削除で消える。

## 権限
- CAMERA: 撮影画面に効果をかけた映像を出し、写真を撮るため
- WRITE_EXTERNAL_STORAGE(Android 9 以前だけ): 写真の保存
- INTERNET / ACCESS_NETWORK_STATE / BILLING: 購入と購入の確認
- VIBRATE: シャッターを押したときの小さな振動

## 広告
- 広告を含む → いいえ

## 対象年齢
- 13歳以上を対象(全年齢で使えるが、子ども向けに作ったアプリではない)
